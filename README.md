# SQL Hands-On Practice

## About This Repository

This repository contains my solutions to SQL exercises and hands-on practice problems as I build my SQL skills. I am using these exercises to strengthen my understanding of relational databases, query writing, and data analysis.

My goal is to develop strong SQL fundamentals through consistent practice and apply them to real-world data problems.

## Topics Covered

- Basic SQL queries (`SELECT`, `WHERE`, `ORDER BY`)
- Filtering and sorting data
- Aggregate functions
- `GROUP BY` and `HAVING`
- SQL joins
- Subqueries
- Conditional logic
- Working with multiple tables

*Topics will be updated as I progress.*
